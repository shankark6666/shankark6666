## 🚀 Featured Project: Craveo

> A multi-city food delivery platform for India — designed and built solo.

| Repo | What it is |
|------|------------|
| `craveo-backend` | Spring Boot modular monolith with hexagonal modules — geography, restaurant, cart, order, payment, delivery |
| `craveo-customer` | Customer-facing ordering app |

**Highlights:** PostgreSQL + Flyway · Redis geospatial delivery-partner matching · Kafka async events between modules · Go GPS-tracking sidecar · GraphQL read API · optimistic locking · Docker on AWS
